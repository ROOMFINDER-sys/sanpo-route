SANPO mobile v12

今回の変更:
- 男女5段階のキャラクター画像を実装
- 0% / 25% / 50% / 75% / 100% の5段階
- キャラ変化は「今日歩いた距離 ÷ 1日の目標距離」で判定
- 毎日の日付が変わると今日の距離が0から始まるため、キャラも0%へ戻る
- ホームの川沿い背景は固定し、人だけが達成率に応じて差し替わる
- 散歩中もGPS距離が増えるとキャラ画像が段階的に変化
- 体型変化プレビューはホームから削除し、設定画面へ移動
- 設定画面で男女を切り替えると、5段階プレビューも即座に切り替わる

段階:
Stage 1 = 0〜24.9%
Stage 2 = 25〜49.9%
Stage 3 = 50〜74.9%
Stage 4 = 75〜99.9%
Stage 5 = 100%以上

ZIPは必ず「すべて展開」してから index.html を開いてください。
GitHub Pagesへ公開する場合は、このフォルダ内をそのままリポジトリへ配置できます。
